Getting started

  1. Add an image folder and scan it.
  2. Write a default prompt for image-to-video motion.
  3. Review providers - every one starts disabled and unverified.
  4. Set up manual assist for the websites you use by hand.
  5. Queue a test job against the mock provider first.
  6. Point the app at FFmpeg so clip durations can be measured.
