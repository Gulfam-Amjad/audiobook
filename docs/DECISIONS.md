# Decisions

## Local process, not a worker farm

Python, FastAPI and SQLite in one process. The laptop has 8 GB of RAM and
little free space on C:, so there is no Node build, Docker, Redis or Celery.
Queue state is in the database, so closing the browser does not lose jobs.

## Cloud generation, local filing

Video is generated by providers. This PC scans images, queues jobs, downloads
results and assembles them. Local AI video models are not required.

## Manual assist instead of browser automation

The only recurring free video is on consumer websites, and most of those
sites forbid bots. The app writes a worksheet and watches a folder.

## Honesty rules that the code enforces

- Paid generation needs three switches: the global toggle, a monthly cap
  above zero, and per-account authorisation. Turning the toggle off withdraws
  every authorisation.
- A submit that times out is `uncertain` and is not retried or moved to
  another provider until reconcile says what happened.
- A balance is `api_verified`, `user_entered`, or `unknown`. Unknown is not
  stored as zero. A passed reset blanks the figure; it does not refill it.
- `verified` on a provider means a real file was saved. A credential check
  does not set it.
- Generated seconds come from FFprobe. Assembled duration is stored on the
  assembly and is not added to the generated total.

## IPv4

HTTP clients bind to `0.0.0.0` because IPv6 routes from this network to
Fastly accept the TCP connection and then hang.

## Secrets

Keys stay in `.env`. They are not rendered into pages. Log lines and provider
error text pass through a redactor before display. The diagnostic download
does not read the environment.
